#  مشروع هندسة بيانات سيارات في اليمن  (Yemen Cars Pipeline)

##  نبذة مختصرة عن المشروع

هو عبارة عن نظام يقوم بتجميع بيانات السيارات المعروضة للبيع أو الشراء في اليمن من موقع "السوق اليمني المفتوح" ،
ثم تخزينها كبيانات خام، وبعد ذلك تنظيفها وتوحيدها، وأخيراً تقديمها عبر API يمكن الوصول إليها كخدمة يمكن تثبيتها وتشغيلها على Ubuntu.
